 Système Automatisé de Démarrage Étoile-Triangle à Deux Sens de Rotation

 Description du projet

Ce projet présente la conception et la réalisation d’un système automatisé de démarrage étoile-triangle d’un moteur asynchrone triphasé avec inversion du sens de rotation, signalisation lumineuse et supervision à distance via Blynk IoT.

Le système a été développé dans le cadre d’un mémoire de Licence Professionnelle en Génie Électrique à l’UATM-GASA.

L’architecture repose sur une carte Arduino UNO associée à un module Wi-Fi ESP8266 permettant la commande locale par boutons poussoirs ainsi que la supervision distante depuis un smartphone grâce à l’application Blynk.



 Fonctionnalités principales

- Démarrage étoile-triangle automatique
- Inversion de sens de rotation
- Signalisation par voyants lumineux
- Commande locale par boutons poussoirs
- Supervision et commande à distance via Blynk IoT
- Temporisation automatique avec temps mort de sécurité
- Gestion des contacteurs par modules relais

 Technologies et logiciels utilisés

 Matériels
- Arduino UNO
- ESP8266
- Modules relais 2 canaux
- Contacteurs
- Voyants lumineux
- Boutons poussoirs

 Logiciels
- Arduino IDE
- AUTOMGEN
- APIMOU
- Proteus
- Blynk IoT
